연결 확인 중
안녕하세요. 할 일을 알려주시거나 “브리핑해봐”라고 해주세요.

음성 입력은 입력칸을 누른 뒤 Win+H를 사용하세요. 상시 “자비스” 호출은 준비 중이에요.

브라우저 연결 · 음성 설정

Chrome 또는 Edge에서 확장 관리 → 개발자 모드 → 압축해제된 확장 로드로 아래 폴더를 추가하세요. 확장 아이콘을 열어 연결 코드를 붙여넣고, 로그인한 자비스 사이트 탭을 열어두세요.

앱을 다시 실행하면 연결 코드도 새로 발급됩니다.

현재 연결 규격: POST {text, language} → audio 응답. 맥의 실제 규격을 받으면 맞춰 연결합니다. 비워두면 윈도우 기본 음성을 사용해요.

창을 닫아도 실행돼요. 완전히 종료하려면 트레이의 자비스 메뉴를 이용하세요.
