# 자비스 Windows 시험 앱

## 실행

`dist/win-unpacked/Jarvis.exe`를 실행한다. 창을 닫으면 트레이에 남고, 트레이 메뉴의 자비스 종료로 종료한다. 앱을 고정 폴더에 둔 뒤 설정에서 Windows 로그인 시 시작을 켤 수 있다.

## 기존 사이트 연결 (사이트 수정 없음)

1. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 연다.
2. 개발자 모드를 켜고 압축해제된 확장 로드로 앱의 설정 → 확장 폴더 열기에 표시되는 폴더를 선택한다.
3. 앱에서 연결 코드 복사 후 확장 아이콘을 눌러 붙여넣고 연결한다.
4. `https://www.oneaigen.com/jarvis`를 기본 브라우저에서 열고 소유자로 로그인한다. 설치 전에 열려 있던 탭은 새로고침한다.
5. 브라우저 탭을 열어둔다. 확장이 이 탭을 통해 기존 API를 호출한다. 비밀번호나 로그인 쿠키를 앱으로 복사하지 않는다.
6. 앱에서 ‘내일 보고서 작성 할 일 등록해줘’, ‘브리핑해봐’를 시험한다. 결과를 기존 `/todo` 화면에서 확인한다.

연결 코드는 앱을 시작할 때 새로 발급한다. 재실행 후 확장에 새 코드를 입력해야 한다. 브라우저의 소유자 로그인과 실제 저장은 별도 사용자 시험이 필요하다.

## 음성

입력칸 선택 후 Windows의 Win+H 받아쓰기를 사용하고 Enter로 보낸다. `자비스` 상시 호출 및 자체 음성 인식은 미구현이다. 기본 읽기는 Windows에 설치된 한국어 음성으로 동작하며, 자연스러운 여성 음성은 Mac 서버 준비 후 연결한다.

‘안내 멈춰’, ‘회의하니까 안내 멈춰’, ‘다시 시작해’ 명령과 버튼/트레이 메뉴를 제공한다. 현재 앱은 메일 수신 기능이 없어 밀린 메일을 모으지 않는다. 약속 자동 알림은 만들지 않았다.

Mac 어댑터 초안: 설정한 URL에 `POST {"text":"읽을 내용", "language":"ko"}`를 보내 `audio/wav` 등 오디오 응답을 받는다. 시간제한 30초, 최대 20MB. 인증 및 실제 서버 규격은 전달받은 후 맞춘다. 서버 준비 전에는 주소를 비워둔다.

## 개발·검증

`npm ci`, `npm test`, `node smoke.cjs`, `npm run pack`.

스모크 테스트는 가짜 브라우저 연결로 IPC 왕복, 중지·재개, 창 닫기 후 유지, 연결 끊김을 검증한다. 실제 Gmail, Calendar, 통화, 브라우저 로그인, 받아쓰기, Mac 음성은 이 테스트에 포함되지 않는다.

네트워크: 연결 서버는 127.0.0.1:17843만 수신하며 확장 Origin과 매 실행마다 바뀌는 토큰을 검사한다. 확장은 oneaigen.com에만 접근하며 임의 URL 실행이나 쿠키 추출 기능이 없다. 앱 UI는 로컬 파일만 로드하며 Node 접근 없이 샌드박스에서 실행된다.
