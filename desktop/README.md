# 자비스 Windows 0.3

0.3 통합: 고대비 흰색 J 트레이 아이콘, 실제 마이크 파형, 선택 가능한 ‘자비스 호출 듣기’, 상주 ASR worker, Mac Supertonic 3 F1 음성 연결. 호출 듣기를 켜면 창을 숨겨도 마이크가 유지됩니다. 끄면 녹음 중이 아닌 경우 마이크를 해제합니다. 앱이 답변을 처리하거나 읽는 동안에는 자기 목소리를 인식하지 않도록 호출 감지를 잠시 건너뜁니다. 이때 안내 중지는 버튼/트레이 메뉴를 사용합니다.

‘자비스’만 말하면 다음 명령을 듣고, 말을 멈춘 뒤 자동 전송합니다. ‘자비스, 브리핑해봐’처럼 한 번에 말해도 됩니다. 버튼 녹음은 기존처럼 전송 전 편집합니다. 주변 소음/발음에 따라 호출이 누락될 수 있는 시험 기능입니다. 음성 대화는 여전히 기존의 제한된 할 일 명령을 처리하며 범용 AI 대화 엔진은 아닙니다.

인식은 small(명령), base(호출) 모델을 메모리에 유지합니다. 합성된 한국어 테스트에서 호출 추론 0.77~0.84초, 반복 명령 추론 약 2.1~2.5초였습니다. 호출 감지에는 별도 약 0.45초의 무음 대기가 더해지고 앱 최초 모델 로딩은 별도입니다. 실제 사용자 음성/기기 상태에서는 달라집니다.

Mac은 현재 http://192.168.0.22:8765/tts 에서 F1, 속도 1.1로 응답하며 인증 토큰은 Windows DPAPI 파일에 저장했습니다. 토큰은 해당 origin에만 전송합니다. 짧은 통합 시험 문장의 HTTP 오디오 응답은 약 1초였습니다. 문장 단위로 합성하고 다음 문장을 미리 요청하며 짧은 결과는 메모리 캐시를 사용합니다. 개인 LAN HTTP 연결이며 외부 공개 설정은 하지 않았습니다. Mac 서버는 실행 중이나 launchd bootstrap이 실패하여 재부팅 후 자동 시작은 아직 검증되지 않았습니다.

통합 시험: node integration-smoke.cjs (합성 오디오를 가상 마이크로 사용), 실제 소유자 읽기 전용 브리핑 응답, 실제 Mac 인증 TTS, 호출 명령 경로, 트레이 유지. 일반 명령은 시험용 응답으로 대체하여 실제 할 일 변경을 하지 않습니다. 실제 물리 마이크/Windows 숨겨진 아이콘 배치는 사용자 확인 대상입니다.

마이크 버튼을 누르면 녹음이 시작되고, 다시 누르면 한국어를 글로 변환해 입력칸에 넣습니다. 내용을 확인해 보내기를 누릅니다. 녹음은 최대 60초이며 창을 숨기면 취소하고 마이크를 해제합니다. 추가 API 비용 없이 로컬 faster-whisper small 모델을 사용하며 오디오를 서버에 전송하거나 파일로 저장하지 않습니다. 실제 물리 마이크 품질은 사용자 환경에서 확인해야 합니다.

개발 환경에서는 requirements-speech.txt를 설치하고 그 Python으로 setup_speech.py를 실행한 뒤 빌드합니다. 이 컴퓨터에는 설치 완료했습니다. 실행 파일 외에 기존 Python 가상환경 및 desktop/models 폴더도 필요하므로 프로젝트 폴더를 삭제하지 마세요. 다른 컴퓨터로 복사할 때는 해당 환경을 다시 준비해야 합니다.

실행: dist/v0.2.0/win-unpacked/Jarvis.exe → Google로 로그인 → 브라우저에서 본인 계정 선택. 로그인 완료 후 브라우저를 닫아도 됩니다. 확장 기능과 연결 코드는 필요 없습니다.

로그인 정보는 Windows DPAPI로 암호화해 앱 데이터 폴더에 저장하며 30일 후 재로그인합니다. 로그아웃은 이 기기의 저장된 인증을 삭제합니다. 원격 기기별 인증 폐기는 아직 없습니다.

창을 닫으면 트레이에서 유지합니다. 종료는 트레이 메뉴를 사용하세요. 고정 폴더에 두고 설정에서 Windows 로그인 시 시작을 켤 수 있습니다. 입력칸 선택 후 Win+H로 받아쓰고 Enter로 보냅니다.

현재 기능: 기존 사이트 할 일 등록과 브리핑, 안내 중지/재개. 상시 호출, 메일 수신, 통화 분석, Calendar 동기화는 후속 단계입니다. 자연스러운 여성 음성은 Mac 서버 준비 후 연결합니다.

Mac 음성 규격 초안: POST {text, language: ko} → audio 응답. 30초, 최대 20MB. 실제 규격을 전달받으면 맞춥니다.

인증: 기본 브라우저 Google OAuth, 임시 loopback 포트, 난수 state, PKCE. 기존 Google callback을 사용하므로 새 리디렉션 URI 등록은 필요 없습니다. 목적별 서명으로 브라우저 쿠키와 앱 토큰을 분리하고 매 요청 소유자 권한을 검사합니다. state 5분, grant 60초, access 30일입니다. Stateless grant의 동일 verifier 재교환을 TTL 안에서 별도 DB로 차단하지는 않습니다. Access token은 URL과 렌더러에 노출하지 않습니다.

검증: Python 전체 테스트, npm test, node smoke.cjs --packaged. Google 및 저장소 교환은 모의 테스트하며 실제 소유자 로그인은 사용자가 마지막으로 확인해야 합니다.
